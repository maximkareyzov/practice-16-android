# Практическая работа 16.1–16.6

Учебное Android-приложение на Java: список пользователей и просмотр/редактирование профиля.

## Что реализовано

- `ListView` с собственным `BaseAdapter`, модель `User` и демонстрационные пользователи.
- В портретной ориентации профиль открывается поверх списка, в горизонтальной — справа от списка.
- Индикаторы подключения: 0 — офлайн (серый), 1 — онлайн (зелёный), 2 — отошёл (красный).
- Редактирование имени, возраста и текстового статуса в `UserActivity`; кнопки возврата и сохранения.
- Обновление списка и профиля после редактирования, общие стили и `Transform.parseIntOrDefault`.

Данные хранятся в статическом списке, как в задании: изменения действуют до завершения процесса приложения, не сохраняются на диск. Статус подключения — демонстрационное поле, а не проверка сети.

## Запуск

1. Открыть папку проекта в Android Studio, установить Android SDK Platform 35 и JDK 17.
2. Дождаться Gradle Sync и запустить `app` на устройстве или эмуляторе Android 6.0 (API 23) и выше.
3. Выбрать пользователя, нажать значок карандаша, изменить данные и сохранить. Повернуть устройство для проверки горизонтальной разметки.

Для сборки из терминала: `./gradlew assembleDebug` (при установленном Android SDK и заданном `ANDROID_HOME`). Тест преобразования строки: `javac -encoding UTF-8 -d /tmp/practice16-test app/src/main/java/com/example/practice16/Transform.java tests/TransformTest.java && java -cp /tmp/practice16-test TransformTest`.
